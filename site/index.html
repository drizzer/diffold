Why diffold

Content-aware by default

Files present everywhere are fingerprinted with streaming SHA-256 and split into identical vs changed. Pass -c for presence-only.

Matrix first

One row per file, one column per folder. M marks the folder holding a variant nobody else shares. Agreement rows hide unless --verbose.

  • Readable at scale. Sections cap at 20 entries; a real 684-vs-584-file tree renders in 30 lines instead of 592.
  • Machine-readable. --json prints a versioned report; -f writes either format to a file with stdout empty.
  • CI gate. Exit 0 success, 1 differences with --fail-on-diff, 2 usage or fatal — incomplete runs always exit 2.
  • Safe traversal. Depth and file-count limits, symlink skipping, path containment, terminal-safe output. Zero runtime dependencies.

One view for which folder is different?

Comparing three or more trees with per-folder lists means holding every list in your head at once. The matrix puts every file on one row so the answer is positional: scan the row, find the column that disagrees.

Matrix (default)

$ diffold dir1 dir2 dir3
only-a.txt  Y  -  -
only-b.txt  -  Y  -
shared.txt  Y  Y  M

Per-folder list

$ diffold dir1 dir2 dir3 --list
Folder 1: unique only-a.txt
Folder 2: unique only-b.txt
Folder 3: missing both
Common: 1 file, 1 changed

Prefer lists for two folders or per-tree audits: --list / -l. Explicit matrix alias: --matrix / -m.

Built for pipelines

# Fail the job only when trees genuinely differ
diffold build-a build-b --fail-on-diff
  • Exit 0 clean, 1 differences (opt-in), 2 broken input
  • --json hands a typed report to the next step
  • -f saves evidence without touching stdout

Docs

Options

-c, --no-content   paths only
--json             machine-readable
-e, --exclude      repeatable globs
-v / -q            all rows / counts only
-f [path]          write report to file

Install and run

npx diffold dir1 dir2
bunx diffold dir1 dir2 dir3
npm i -g diffold

Requires Node.js 22+ or Bun 1.4+. Deno source runs are best-effort.
